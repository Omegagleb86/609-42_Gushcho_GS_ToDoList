# Локальная база SQLite и разделение слоёв

```text
ToDoList (MAUI: Views, ViewModels)
  ├── ToDoList.Core → ToDoList.Models
  └── ToDoList.Data → ToDoList.Core → ToDoList.Models
```

- **Models** — независимые контракты Category, TodoTask и TodoState.
- **Core** — TodoRules, TodoService и интерфейс ITodoRepository.
- **Data** — EF-сущности, TodoDbContext, EfTodoRepository и фабрика SQLite.
- **ViewModels** — состояние экрана и команды, обращающиеся к TodoService.

## Хранение на устройстве

MAUI-приложение всегда использует SQLite через Entity Framework Core.
База находится в `Path.Combine(FileSystem.AppDataDirectory, "todolist.db3")`.
Путь выбирается платформой: Windows, Android, iOS или Mac Catalyst.
Каталог доступен приложению для записи; интернет и отдельный сервер не нужны.
Все необходимые библиотеки приходят с NuGet-пакетами и приложением.
Пользователь не устанавливает СУБД и не вводит логин, пароль или строку подключения.

`SqliteTodoRepositoryFactory.Create(databasePath)` создаёт каталог и настраивает
провайдер SQLite. При первой операции EF `EnsureCreatedAsync` создаёт файл базы,
таблицы `Categories` и `Tasks`, индексы и внешние ключи. Повторный запуск читает
тот же файл. Данные сохраняются после закрытия приложения. Удаление данных
приложения или его деинсталляция может удалить локальную базу.

Подключение зарегистрировано в `ToDoList/MauiProgram.cs`. Автоматического
переключения на память нет: ошибки записи отображаются в интерфейсе.
`InMemoryTodoRepository` используется в тестах команд и не зарегистрирован в приложении.

## Поведение

- Сохраняется полный снимок одного списка задач с порядком и Guid записей.
- ParentId — необязательная ссылка на родителя; CategoryId — на категорию.
  Внешние ключи SQLite включены в строке подключения фабрики.
- Сохранение и удаление выполняются в одной транзакции. При ошибке старое
  состояние базы сохраняется целиком. Изменения в UI можно сохранить повторно.
- Название сохраняется по Enter или потере фокуса, категория и статус — сразу.
  Названия содержат 1–255 символов после удаления пробелов по краям.
- Статус родителя и потомков независим. Удаление родителя удаляет его ветку.
- При удалении категории задачи и подзадачи сохраняются, их категория сбрасывается
  в «Без категории». Удаление категории и очистка ссылок сохраняются одной транзакцией.
- Category.None — элемент интерфейса, не запись базы данных.

Инициализация через EnsureCreated создаёт начальную схему, но не обновляет
существующие таблицы при изменении модели. Для будущих изменений схемы нужно
отдельно организовать версионирование или переход на миграции.

## Проверки

Из общей папки проектов:

```bash
dotnet test ToDoList.Tests/ToDoList.Tests.csproj
dotnet build ToDoList/ToDoList.csproj -f net10.0-maccatalyst -t:Compile
```

Тесты ORM используют отдельную SQLite-базу в памяти на каждый тест и проверяют
чтение, обновление, удаление, вложенность и откат транзакции при сбое.
Отдельный тест фабрики создаёт временный файл, сохраняет данные и проверяет
загрузку через новый экземпляр репозитория. Файл удаляется после теста.
Рабочая база приложения тестами не затрагивается.
