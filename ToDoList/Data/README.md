# Хранение данных

ViewModel зависит только от `ITodoRepository`. Сейчас через DI зарегистрирован
`InMemoryTodoRepository`: данные живут до закрытия приложения.

Для подключения MySQL/ORM реализуйте `ITodoRepository` в отдельном слое Data
(при необходимости — в отдельном проекте) и замените регистрацию в `MauiProgram`.
Модели передачи данных находятся в Models; ORM-сущности и контекст БД не должны
попадать во View и ViewModel.

`LoadAsync` загружает категории и дерево задач. `SaveAsync` сохраняет полный
снимок атомарно: категории, названия, статусы, связи родителей и подзадач,
а также удаляет отсутствующие в снимке записи. Связь с категорией необязательна.
`Category.None` используется только интерфейсом и не хранится в репозитории.
Для дерева в БД подойдёт отдельная таблица задач с nullable ParentId и CategoryId.
Удаление задачи должно удалять потомков в той же транзакции.

Смена статуса родителя не меняет статусы потомков. Название сохраняется по Enter
или при потере фокуса; пустое название отклоняется. Категория и статус сохраняются
сразу. Сохранения выполняются последовательно. При ошибке изменения остаются
в памяти, сообщение и кнопка повтора позволяют повторить сохранение.

Проверки логики без MAUI: `dotnet run --project Tests/LogicChecks.csproj`.
